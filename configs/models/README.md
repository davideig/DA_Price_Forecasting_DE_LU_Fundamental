# Additional Runnable Models

This directory contains reusable model specifications that are not selected by
the default operational cutoff runner.

- `price/`: controlled `P_base`, `P_load`, `P_ren`, and no-weather generated
  input variants.
- `renewable/`: retained solar ensemble and full-weather wind alternatives.

These are model configs only. Retrospective evaluation grids, metric reports,
and thesis figure generation are maintained in the separate reproducibility
repository.

See `configs/FINAL_MODELS.md` for the corresponding Pixi commands.
